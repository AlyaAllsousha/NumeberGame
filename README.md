# Numbers — Обучающая игра «Состав числа» 

**Numbers** — это образовательное Android-приложение в формате математической игры, направленное на тренировку устного счёта и изучение темы «Состав числа». Приложение включает полноценный игровой сценарий: от выбора уровня сложности до подсчёта детальной статистики по итогам раунда.


## 🎯 Основной функционал

* **Выбор уровня сложности:** Настройка параметров игры (время раунда, необходимый процент правильных ответов, диапазон чисел) в зависимости от выбранного уровня.
* **Динамическая генерация заданий:** Алгоритм создаёт уникальные математические задачи и варианты ответов для каждого раунда.
* **Интерактивный геймплей:** Таймер обратного отсчёта, мгновенная проверка ответов и визуальная индикация прогресса (процент правильных ответов в реальном времени).
* **Итоговая статистика:** Экран результатов с подробным отчётом о прохождении (победа/поражение, набранные очки, точность ответов).

## 🛠 Технологический стек

* **Язык:** [Kotlin](https://kotlinlang.org/)
* **Архитектура:** Clean Architecture + MVVM (Model-View-ViewModel)
* **Вёрстка и работа с UI:** XML, View Binding
* **Навигация:** Jetpack Navigation Component + Safe Args

##  Архитектура проекта

Проект разработан с соблюдением принципов **Clean Architecture**, что обеспечивает слабую связность компонентов и упрощает развитие игровых механик без необходимости изменения пользовательского интерфейса:

1. **Domain Layer (Доменный слой):**
   * Содержит чистую бизнес-логику приложения и не зависит от Android SDK.
   * Описывает основные сущности (`GameSettings`, `Question`, `GameResult`, `Level`), интерфейс репозитория и UseCases (генерация вопроса, получение настроек игры).

2. **Data Layer (Слой данных):**
   * Реализует интерфейс репозитория из доменного слоя.
   * Отвечает за логику генерации математических заданий, вариантов ответов и конфигурацию уровней сложности.

3. **Presentation Layer (Слой представления):**
   * Реализован с использованием паттерна **MVVM**.
   * Экраны построены на базе `Fragments` (Single Activity подход) с использованием **View Binding** для безопасной работы с UI-элементами.
   * Переходы между экранами и типобезопасная передача параметров (выбранный уровень сложности, итоговый результат игры) организованы через **Navigation Component** и плагин **Safe Args**.
